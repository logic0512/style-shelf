# 图片索引与风格卡片修复回顾

## 交付边界

通用修复进入原版仓库，并同步到本机安装版。原版保留仓库原有的 8 个内置 Skill 和 5 个 Prompt；用户额外导入的 Skill、Prompt、封面、上传图片、生成结果及任务索引不进入 GitHub。本次不修改原始 Skill 或 Prompt 的执行正文。

## 问题与处理

| 问题 | 已确认根因 | 本轮处理 |
| --- | --- | --- |
| 重启后封面、图库图片空白 | 索引保存了旧服务端口，文件本身仍在 | Job 图片引用无端口保存，读取时映射当前服务；覆盖 Skill、Prompt、样例及图库 |
| 浏览器打开桌面页面连接错误 | 无桌面桥接时固定请求默认端口 | 生产网页默认同源，桌面桥接和显式配置优先；开发环境保留原端口约定 |
| 相对图片路径保存失败 | 写入接口与存储接受的地址格式不一致 | 接口兼容相对 Job 地址，真实服务测试覆盖写入、读取及换端口重启 |
| Windows 生成图片归档失败 | 本地文件绝对路径校验只接受以 / 开头的路径 | 共享归档函数使用平台路径判断，继续保留真实路径白名单与图片签名检查；跨平台真实 API 测试覆盖 |
| 更新程序后自定义封面可能失效 | 自定义素材放在程序发行目录，安装替换可能移除 | 服务支持独立数据目录下的封面，仍校验真实路径；本机现有封面已备份到该目录，原版保留内置资源回退 |
| 静态预览无法读取目录 | 生产同源请求需要预览服务转发接口 | Vite preview 转发 /api 到配置的本地服务端口 |
| 索引损坏可能覆盖用户目录 | 单条 Skill 记录非法时回退内置目录，后续写入覆盖原目录 | 文件存在但非法时明确报错，禁止写入；仅文件不存在时初始化。前端不再静默展示默认目录 |
| 卡片裁掉标题、分镜和对照信息 | 4:5 图片框强制 cover，悬停再次放大 | 默认 contain 居中完整展示；可选择铺满裁切，保留取景；取消悬停缩放 |
| Prompt 缺少封面控制 | 只有 Skill 有更换封面入口 | 两类风格共用同一封面编辑器，按对应来源筛选结果并保存设置 |
| 小窗口标签、作者和按钮挤压 | 固定底栏/正文高度、绝对定位按钮和固定列数 | 自动调整列数，标题/摘要/操作/标签按正常流布局，底栏允许内容换行 |
| Prompt 卡片不齐、标题显示不完整 | 标题、类型标识、操作混在同一窄行 | 标题独占两行空间，类型和操作分区，两个页面采用同样排版规则 |
| 长说明和来源链接遮蔽重点 | 直接在卡片及工作区展示完整说明 | 优先已有摘要，按句/分句边界生成短摘录；完整说明和来源折叠展示，正文保持原样 |

摘要采用确定性的展示摘录，不调用额外模型，不把截取描述称为已重新理解整个 Skill。专业摘要可通过原有资料字段维护；来源与许可仍保留在完整说明中。

## 验证要求

- 原版干净目录：仅原有内置目录，测试、构建、许可检查通过；发布产物不得夹带用户新增素材。
- 索引：旧绝对地址、无端口地址、不同重启端口、非法 JSON、单条非法记录；损坏文件字节保持不变。
- 图片：真实 API 发布和重新读取图片，检查 HTTP 状态、类型及字节；不可用默认封面遮掩错误。
- 页面：Skill 与 Prompt 分别检查宽屏、普通窗口和窄窗口；标题、摘要、按钮、标签、来源互不覆盖，图片完整展示。
- 封面：完整展示/裁切切换，保存与回读一致；Prompt 只能选择自己的结果。
- 本机安装版：更新前检查运行中任务并备份被替换程序文件，保留用户数据和素材。

## 发现但未扩大实施的事项

- 部分 Skill 包含 PDF、视频或工程流程，单张图片成功不能代表完整流程验证；本轮不改第三方 Skill 执行内容。
- 自定义图片库使用系统路径别名时仍受现有真实路径校验约束；不通过放宽路径安全检查解决，需要单独验证合法别名与越界符号链接。
- 历史任务页、图库的取景需求和风格封面不同，保留图库已有比例选择，不批量修改用户已有图库取景。

## 本轮验收记录

- 0.2.1 原版隔离目录：13 项测试全部通过，生产构建通过，8 个内置 Skill 许可检查通过；静态预览接口返回原有 8 个 Skill。
- 真实服务测试验证换端口后的图片字节、本地独立封面、发行版资源回退；指向数据目录外的符号链接返回 404。
- 本机重启后 26 个 Skill、15 个 Prompt 封面均正常加载；自定义素材保存在用户目录，不提交仓库。
- 浏览器检查 390、960、1280 像素窗口；卡片无横向溢出，窄窗口顶部操作分行，标题、操作、标签独立排布。
- Prompt 封面切换裁切后重新打开仍保持选中，再恢复完整展示；相同存储契约覆盖 Skill。
- 独立代码审查未发现阻塞问题。摘要为展示摘录，完整描述、来源及执行正文保留。
