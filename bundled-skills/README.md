# Bundled Skills

These eight third-party Skill directories are copied into the user's Codex
Skill directory only when the same Skill is missing. Existing user files are
never overwritten.

Each directory retains its upstream license. Source, author, pinned version,
and license file are recorded in `manifest.json` and summarized in
[`THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md).

`heytea-doodle-poster` is a maintainer-local copy included only in the free
personal/non-commercial package. Its upstream redistribution permission was
not independently verified; see its `REDISTRIBUTION-NOTICE.md`. Private
reference assets are intentionally excluded.

The presence of a Skill in this repository does not relicense it under the
Style Shelf core license. In particular, the two Gathered Scenes Skills and
`photo-abstract-editorial` are restricted to personal/non-commercial use.
